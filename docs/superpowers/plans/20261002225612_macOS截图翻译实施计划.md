# 小安翻译 macOS 截图翻译实施计划

> **面向 AI 代理的工作者：** 使用 superpowers:executing-plans 逐任务执行；需要子代理时可使用 superpowers:subagent-driven-development。先读本计划和配套方案，再按复选框推进。当前只完成文档编写，没有实施代码。

**目标：** 为 macOS 14+ 交付快捷键截图、设备端 OCR、百度 API 翻译和截图下方译文；保留 Android/iOS ML Kit，并提供 macOS 15+ 苹果离线翻译扩展。

**架构：** 复用 TranslationService、Riverpod、Dio、SQLite 和单个 Flutter 引擎。macOS 原生处理权限、选区、OCR、快捷键与窗口位置；Flutter 管理独立截图会话、设置和结果。

**技术栈：** 当前官方 Flutter/Dart、Dio、sqflite、flutter_secure_storage、crypto；Swift/AppKit/ScreenCaptureKit/Vision/NaturalLanguage；扩展阶段使用 Translation/SwiftUI。

- 日期：2026-10-02（Asia/Shanghai）。
- 状态：P0～P3 已按用户明确要求开始代码实施（不提交）；Task 0～3 完成并通过针对性测试，Task 4 起进行中。本文件不构成构建、真机或发布完成证据。
- 配套：[需求调研](../../01_prd/20261002225612_macOS截图翻译需求与选型调研.md)、[实施方案](../../02_design/20261002225612_macOS截图翻译实施方案.md)。
- 默认交互：结果窗内截图在上、中文译文在下，窗口靠近选区。
- 当前最低 macOS 配置是 10.15；计划调整为 14，Apple 功能运行时限制为 15+。
- 当前仅交付文档。开始代码实施需用户明确要求；代码提交、推送、设备安装和发布需要对应授权。
