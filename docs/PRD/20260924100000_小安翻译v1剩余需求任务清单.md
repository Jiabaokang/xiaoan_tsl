# 小安翻译 v1.0 剩余需求与任务清单

状态：实施中。依据《小安翻译 v1.0 第一版功能计划与开发文档》及当前 Flutter 工作区。此前的模拟翻译与核心框架属于开发基线，不等同于可发布的 v1.0。

## 目标与范围

Android 首版完成“输入 → 真实识别或手选语言 → 下载所需模型 → 设备端翻译 → 复制、分享或朗读 → 本地历史与收藏”的闭环，并形成可验证的 Release AAB 和 Google Play 测试材料。保持现有四个入口、SQLite 数据与旧 JSON 迁移兼容。

采用独立的 ML Kit 翻译和语言识别 Flutter 插件；不使用包含全部 ML Kit 功能的聚合包。现有 TranslationService 继续作为翻译边界，模型管理和语言识别各通过可注入的服务访问插件。模型下载交给 ML Kit，不经过 Dio，不把“已下载”状态写入 SQLite。

## 实施前基线

- 原文输入、目标/源语言手选与互换、复制/系统分享入口、历史/收藏/搜索/删除、SQLite 持久化、设置与深色模式已经有代码及组件测试。
- 译文仍由 DemoTranslationService 生成；自动识别仅使用字符规则；离线语言包页只有说明；隐私与关于页是演示文案。
- 之前通过的是 Android Debug APK 和 iOS 模拟器启动。Release AAB、Android 真机离线翻译、Play Console 测试均没有验收证据。
- 工作区有未提交的核心框架及文档改动；实施时保留所有现有变更，不重置、不清理、不顺带提交无关文件。

## 关键约束

- 首版仅 Android 作为发布目标；iOS 模拟器可辅助发现界面或插件问题，但不能替代 Android 真机验收。
- 模型查询结果以 ML Kit Model Manager 为准；数据库只保存翻译历史、收藏和设置。旧模拟记录保持可读，并明确区分演示与真实结果。
- 正式应用不再把任意输入回显为“模拟译文”；插件不可用、语言不支持、下载失败均显示可理解的错误。
- TTS 只读出文字，不做语音输入。OCR、相机翻译、账号、云同步、广告、支付和 AI 翻译不属于 v1.0。
- 发布签名密钥、公开隐私政策 URL、Play Console 账号和测试人员属于外部交付条件；代码与可审查材料先完成，再由项目所有者提供最终值和执行账号操作。
- 商店规则及插件兼容性会随时间变化；正式提交前重新核验，不把本计划中的版本或规则当作永久事实。

## 阶段验收口径

1. 每项功能先有针对性测试，再以真机或构建证据确认插件行为；仅通过 Dart 单测不能宣称 ML Kit、TTS 或离线下载已在真机可用。
2. 完成代码阶段运行 dart format、flutter analyze、flutter test，并生成 Android Debug 与 Release 构建结果；失败记录原因及边界。
3. 在未完成 V1-01～V1-09 的真实验收前，对外始终称为开发版或测试版，不宣称 v1.0 正式上架完成。
