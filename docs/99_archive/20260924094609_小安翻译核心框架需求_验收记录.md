# 小安翻译核心框架需求

状态：核心框架阶段已实现并完成本阶段验证。依据现有 v1.0 功能计划、基础架构文档和 2026-09-24 已提交的模拟翻译首页。

## 目标

在保留当前可用的模拟翻译体验和用户本地记录的前提下，建立能接入真实设备端翻译的应用骨架：路由、统一状态、依赖注入、本地数据库、设置和受控网络客户端。核心框架完成后，首页、历史、收藏、设置能通过真实导航访问，数据在重启后仍在。

## 本阶段交付

1. **应用入口与依赖**：`main.dart` 只初始化本地数据库并启动 `ProviderScope`；`app.dart` 挂载主题和 `MaterialApp.router`。`TranslationService` 仍由演示实现提供，页面通过 Riverpod 获取服务，不直接构造插件。
2. **路由**：`go_router` 提供 `/translate`、`/history`、`/favorites`、`/settings` 四个底部入口；语言选择使用 `/languages?mode=source|target|default-target`，带搜索且目标语言不显示“自动检测”。从历史打开记录使用 `/translate?record=<id>`，直接打开该地址也能恢复记录。未知路径提供返回首页的页面。底部导航切换保留翻译输入。
3. **状态与翻译边界**：Riverpod 控制器统一保存输入、源语言、目标语言、识别结果、翻译状态、结果和请求序号。保留 5000 字符限制、空输入禁用、短文本要求手选语言、同语言拦截、旧请求结果失效、失败后重试。当前继续使用明确标注的模拟译文，不展示虚假的模型下载进度。
4. **本地数据**：同一 SQLite 数据库保存翻译记录、收藏状态、默认目标语言和主题。记录有稳定 ID、真实源/目标语言代码及时间戳；重复短时间提交合并。历史支持原文/译文搜索、单条删除和二次确认清空；收藏直接复用记录。所有 SQL 写入使用参数绑定。
5. **旧数据迁移**：首次启动时，将既有 `translation_history.json` 导入 SQLite。导入与迁移标记在同一事务中提交；失败时不覆盖或删除旧文件。成功后保留旧 JSON 作为备份，但不再写入。已有收藏和时间戳必须保留。
6. **设置与主题**：设置页可修改默认目标语言和系统/浅色/深色模式，均持久化；翻译页的本次目标语言可单独修改。设置页提供清空历史、隐私说明与关于入口；隐私说明明确当前模拟阶段的真实数据行为，不冒充正式上架政策。离线模型入口只解释尚未接入，不伪造下载。
7. **网络边界**：按基础架构文档加入一个受控 Dio 实例，设置连接/接收超时，不配置虚构 `baseUrl`，不打印或上传原文、译文。模拟翻译、复制、分享和本地数据流程不使用 Dio。
8. **目录结构**：入口保留在 `lib/main.dart`、`lib/app.dart`；通用基础设施放在 `lib/core/`，按业务能力拆分到 `lib/features/`，外部能力放在 `lib/services/`。收藏复用历史列表，未实现的语音能力不创建空模块；测试按数据库和翻译功能归位。

## 兼容与边界

- 较新的《基础架构文档》明确采用 `sqflite + path`，本阶段以此为准；较早功能计划中的 Drift 和 `shared_preferences` 方案不同时引入。
- 真实 ML Kit 翻译、语言识别、离线模型下载、TTS、正式隐私政策、发布签名及 Google Play 上架属于后续设备能力和发布任务。本阶段保留明确接口或入口，不声称上述能力已实现。
- 不修改鸿蒙 SDK 配置；使用当前官方 Flutter SDK 验证。保留浅色和深色支持，不引入图标库。
- 原有 `share_plus 7.2.2` 的 Android 模块按 API 33 编译，无法通过当前依赖的 AAR 检查；框架阶段升级到 11.1.0 并使用新分享 API。当前 Android 构建仍提示该版本使用 Kotlin Gradle Plugin，待 Flutter 强制内建 Kotlin 时再升级。
- 需求文档与计划先于实现形成；目录修正后同步更新基础架构文档中的目录树。

## 验收标准

- 从四个底部入口及次级地址进入后，页面和返回行为正确；切换入口时翻译输入不丢失。
- 翻译、复制、分享、收藏、历史搜索/重开/删除、默认目标语言和主题设置在对应页面工作；重启后本地数据仍在。
- 用包含收藏与时间戳的旧 JSON 验证一次迁移；再次启动不重复导入；损坏 JSON 不导致已有文件被覆盖。
- `dart format lib test`、`flutter analyze`、`flutter test` 通过；在已启动的 iPhone 模拟器运行并检查浅色、深色页面。Android 构建作为可执行环境允许时的额外验证，不能代替真实 ML Kit 验收。
