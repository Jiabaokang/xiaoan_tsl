## 1. 用户需求与本轮边界

为现有 Flutter 翻译应用增加 macOS 支持。核心场景是在其他应用中阅读英文时，按下用户设置的全局快捷键，鼠标框选屏幕区域，识别英文并翻译成简体中文，在截图内容下方显示译文。

移动端保留 Google ML Kit 端侧翻译，增加用户自行配置 API 凭据的能力。macOS 不能调用不受支持的 ML Kit 原生插件；应有独立的本地 OCR、语言识别与翻译实现。

本轮只编写文档、实施方案和实施计划，不修改应用或平台代码，不安装依赖、不调用收费接口、不发布应用。

### 已明确的要求

| 编号 | 需求 | 成功标准 |
| --- | --- | --- |
| R01 | 支持 macOS 截图翻译 | 在 Mac 上完成快捷键、选区、OCR、翻译、展示闭环 |
| R02 | 可设置全局快捷键 | App 不在前台也可触发；冲突时说明并保留原快捷键 |
| R03 | 英文翻译成中文 | 截图默认 en → zh，不沿用首页双向互换逻辑 |
| R04 | 译文位于截图下方 | 结果窗按“截图在上、中文译文在下”排版 |
| R05 | 保留移动端端侧模型 | Android/iOS 默认仍使用 ML Kit，原模型下载与历史流程正常 |
| R06 | 支持 API 凭据 | 用户可选在线翻译，配置、测试和删除凭据 |
| R07 | 优先免费或低价 | 本地 OCR；优先现有百度账号，评估苹果端侧翻译 |
| R08 | 延续项目界面规范 | 中英文文案、浅色/暗色模式、内置图标和中文代码注释 |

### 当前设计假设

用户尚未明确选择两种“下方显示”效果。首版采用靠近原选区的结果窗，窗内上方是截图、下方是译文。另一种是在原屏幕选区下方仅显示译文；同样保留选区坐标，若用户选择此方式再调整布局。

建议 macOS 首版最低系统版本为 14，以使用 SCScreenshotManager；苹果端侧翻译作为 macOS 15+ 的扩展能力。当前工程目标仍为 10.15，最低版本调整是拟议方案，尚未实施。

首版一次只截取一块显示器上的区域，支持从任意显示器发起；跨显示器拖拽限制在起始显示器。暂不提供连续字幕识别、自动划词、图片内文字替换、Windows/Linux 支持或完整桌面页面重设计。

google_mlkit_translation 的发布者说明仅支持 Android/iOS，其他平台不受支持；它通过原生 Platform Channel 调用 ML Kit，并非可直接在 Dart 中运行的翻译模型。[插件官方页面](https://pub.dev/packages/google_mlkit_translation)

当前服务规格文档中的部分旧接口名称与代码不同。例如实际语言识别方法是 identify，模型查询方法是 isDownloaded。实施计划使用当前代码名称；能力改动完成后再同步固定契约。

## 3. 建议交互

1. App 运行并在菜单栏提供“截图翻译”“打开主窗口”“设置”“退出”。
2. 用户设置快捷键；首版默认建议为 Control + Option + T，注册时检测是否冲突。
3. 按快捷键后，检查屏幕录制权限并取得显示器快照，再显示选区层。
4. 用户拖拽选区，松开后裁剪截图；Esc 取消，不调用 OCR 后的翻译服务。
5. 结果窗立即显示截图与处理状态。OCR 在后台执行，空内容直接提示。
6. 识别到英文后翻译为简体中文。非英文或低置信度不擅自反向翻译，提供“按英文翻译”和“在主窗口调整语言”。
7. 中文译文出现在截图下方；提供复制、重试、重新截图和关闭。
8. 选区靠近屏幕边缘时，结果窗移到可见位置；长译文在窗口内部滚动。
9. 关闭结果窗隐藏窗口，菜单栏继续工作；打开主窗口恢复其原尺寸和首页输入。

截图只在内存中用于本次 OCR 与预览，不默认写入历史或上传。用户主动选择在线服务后，只将 OCR 文字发送到该服务。成功翻译的文字可沿用现有本地历史存储。

## 4. 推荐技术路线与替代方案

| 路线 | 内容 | 优点 | 成本与约束 |
| --- | --- | --- | --- |
| A：原生截图/OCR＋百度 API | Flutter 设置与结果页；AppKit/ScreenCaptureKit/Vision；百度文本翻译 | 复用现有账号，保留选区坐标，本地 OCR | 需要联网、原生桥接和安全凭据存储；推荐首版 |
| B：原生截图/OCR＋苹果端侧翻译 | A 的交互，翻译改用 Apple Translation | 下载模型后离线运行，无云端调用费用 | 自定义 API 从 macOS 15 起；需要模型下载交互与语言可用性验证 |
| C：桌面截图插件＋API | hotkey_manager、screen_capturer，加本地 OCR 桥接 | 框选截图原型接入较快 | 截图插件结果未提供选区屏幕坐标，精准贴靠仍需原生补充 |

苹果提供单帧截图 API、Vision 本地识别以及使用设备端模型的 Translation API。[截图接口](https://developer.apple.com/documentation/screencapturekit/scscreenshotmanager)、[Vision OCR](https://developer.apple.com/videos/play/wwdc2019/234/)、[Translation 介绍](https://developer.apple.com/videos/play/wwdc2024/10117/)

现成插件可作参考。hotkey_manager 支持桌面全局快捷键；screen_capturer 支持区域截图，但其 CapturedData 仅有图像路径、字节和尺寸，不能直接取得选区位置。[快捷键插件](https://pub.dev/packages/hotkey_manager)、[截图插件](https://pub.dev/packages/screen_capturer)、[返回数据类型](https://pub.dev/documentation/screen_capturer/latest/screen_capturer/CapturedData-class.html)

推荐采用 A，核心闭环通过后再增加 B。最终支持用户明确选择本地或在线服务，离线失败时不自动上传文字。

## 6. 翻译服务与费用快照

### 6.1 本地方案与传统翻译 API

| 服务 | 免费额度 | 超出费用／限制 | 建议 |
| --- | --- | --- | --- |
| [Apple Translation](https://developer.apple.com/documentation/translation/translating-text-within-your-app) | 下载模型后设备端运行 | 自定义 API 从 macOS 15 起；检查语言及模型可用性 | macOS 免费离线扩展 |
| [百度翻译开放平台](https://fanyi-api.baidu.com/access/0/1) | 标准版 5 万字符/月；个人认证高级版 100 万字符/月 | 49 元/百万字符；标准版 QPS 1，高级版 QPS 10 | 首版首选 |
| [腾讯云文本翻译](https://cloud.tencent.com/document/product/551/35017) | 500 万字符/月 | 月用量低于 1 亿字符档位为 58 元/百万字符 | 国内免费额度备选 |
| [阿里云通用机器翻译](https://help.aliyun.com/zh/machine-translation/product-overview/pricing-of-machine-translation) | 100 万字符/月 | 50 元/百万字符 | 国内备选 |
| [Azure Translator F0](https://azure.microsoft.com/en-us/pricing/details/translator/) | 200 万字符/月 | 需开通 F0；付费层价格依区域配置核对 | 海外备选 |
| [Google Cloud Translation NMT](https://cloud.google.com/products/translate/pricing) | 50 万字符/月，以每月 10 美元抵扣实现 | 随后 20 美元/百万字符 | 与 ML Kit 不同的在线服务 |
| [DeepL API](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans) | 新 Developer：总计 100 万字符，不重置 | 原 Free 的 50 万字符/月方案已停止新购；付费 Growth 另查账户区域报价 | 试用及质量比较 |

百度翻译开放平台与百度智能云机器翻译并非同一套接入产品。用户现有凭据属于哪一类尚未确认，本表百度免费额度不能套用到智能云账号。[百度智能云文本翻译](https://cloud.baidu.com/product/mt/text_trans)

### 6.2 低价模型与自部署

| 服务 | 价格／免费条件 | 适用性 |
| --- | --- | --- |
| [Qwen-MT-Flash](https://help.aliyun.com/zh/model-studio/model-pricing) | 北京地域输入 0.7 元/百万 Token，输出 1.95 元/百万 Token；有 90 天期限的 100 万 Token 试用额度 | 专用翻译模型，可比较技术文本质量 |
| [DeepSeek Flash](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) | 缓存未命中输入 1～2 元/百万 Token、输出 4～8 元/百万 Token，按时段变化 | 可配置非思考模式，减少短文本等待 |
| [Gemini 2.5 Flash-Lite](https://ai.google.dev/gemini-api/docs/pricing) | 有免费层；付费输入 0.10 美元/百万 Token、输出 0.40 美元/百万 Token | 有地区与限流条件；官方价格表标明免费层内容可用于改进产品 |
| [LibreTranslate](https://docs.libretranslate.com/guides/faq/) | 自部署软件免费；机器资源和维护自负；官方托管 API 收费 | 有明确自托管需求时评估 |

Token 与字符不能直接换算；上述服务未进行相同语料的质量和延迟测试。免费额度按服务账号及套餐计算，不是每台设备单独领取。

### 6.3 个人用量示例

假设每天截图 100 次，每次提交 500 个字符，30 天约 150 万字符，只翻译成一种目标语言。按查询日价格：

- 百度高级版约超出 50 万字符，费用约 24.5 元。
- 腾讯云 500 万字符/月额度可覆盖。
- 苹果端侧翻译不产生云端按量费用。

这是预算示例，不是实际账单。重试、多个目标语言和其他应用共用密钥会改变消耗。

## 8. 验收与证据边界

完成标准包含：macOS 实机快捷键闭环、准确的截图下方译文、菜单栏常驻、权限恢复、Release 在线请求、暗色模式、多显示器定位以及 Android 实体设备回归。

Dart 单元测试不能证明屏幕录制授权、全局快捷键、系统模型下载或 macOS 窗口层级。Android 回归必须使用已连接实体设备和覆盖安装；iOS 支持应有独立平台证据，不能由 Android/macOS 结果推断。

本文件只记录已讨论需求、实现建议和公开资料，所有实现状态均以配套计划中的证据为准。
