# 小安翻译 (Xiaoan TSL) v1.0 核心产品需求规范 (PRD)

> **文档版本**：v1.0  
> **文档状态**：已批准（Active / SSOT）  
> **制定日期**：2026-09-24  
> **目标平台**：Android (API 23+ / 目标 API 36)  
> **发布渠道**：Google Play (Internal Testing -> Closed Testing -> Production)

---

## 1. 产品背景与目标

### 1.1 业务背景
当前 Google Play 开发者账号为 2023 年 11 月后注册的个人开发者账号。按 Google Play 最新政策：
1. **闭环测试要求**：新个人开发者申请正式发布（Production Access）前，必须通过至少 12 名测试人员连续 14 天的 Closed Testing。
2. **账号活跃度维护**：需要尽快上线真实可用、低审核风险的测试版本，降低账号被标记闲置或关闭的风险。

### 1.2 产品定位
**极简、轻量、无需注册、支持完全离线运行的端侧多语言翻译工具。**
不追求庞大复杂的大模型 AI 对话或付费云翻译，专注于“快速启动、本地翻译、隐私安全、开箱即用”。

## 2. 核心用户旅程

```text
[用户输入/粘贴文本] 
      │
      ▼
[自动检测源语言] ──(置信度低/短文本)──> [提示用户手动选择]
      │ (确定语言)
      ▼
[检查离线模型状态] ──(模型缺失)──> [触发模型准备与下载 (默认 Wi-Fi)]
      │ (模型已就绪)
      ▼
[设备端执行翻译] ──> [展示翻译结果卡片]
      │
      ├─► [点击复制] / [点击系统分享]
      ├─► [原文/译文独立语音朗读 (支持停止)]
      └─► [自动写入本地数据库历史记录 (支持收藏与搜索)]
```

## 3. 功能需求详细说明

### 3.1 文本输入与控制
* **字符上限**：最大支持 5,000 个字符。超过时进行友好限制与计数显示。
* **空输入控制**：原文为空时禁用翻译触发，不发起无效模型检测或请求。
* **快捷操作**：输入框支持“一键清空”与“快捷粘贴”。

### 3.2 语言选择与自动识别
* **支持语种**：支持简体中文、英语、日语、韩语、法语、德语、西班牙语等主流离线模型语种。
* **双向切换**：提供源语言与目标语言一键互换功能（互换时若源语言为“自动检测”，则不触发或回退为明确语种）。
* **自动识别约束**：
  * 源语言默认开启“自动检测”；
  * 目标语言**严禁**设置为“自动检测”；
  * 文本少于 4 个字符或识别置信度不足时，阻断自动翻译并提示“文本过短或无法确定语言，请手动选择语言”，避免产生荒谬译文。

### 3.3 离线翻译执行与模型管理
* **端侧翻译**：翻译计算完全在 Android 设备本地完成，不向任何第三方或自建服务器上传原文/译文。
* **按需下载**：翻译时若检测到对应语言模型未下载，自动触发下载流程；默认仅在 Wi-Fi 下下载，蜂窝网络时弹窗提示用户确认。
* **离线语言包管理页**：
  * 提供独立的语言模型管理列表（`/offline-models`）；
  * 展示每个语种模型的下载状态（未下载 / 下载中 / 已就绪）；
  * 支持用户手动下载或删除已下载的模型以释放存储空间；
  * **保护约束**：正在执行翻译任务所依赖的模型，在翻译完成前禁用删除按钮。

### 3.4 结果交互与辅助功能
* **结果展示**：以卡片形式展示译文，区分加载中骨架/进度、成功卡片与错误状态。
* **复制与分享**：
  * 点击复制：写入系统剪贴板并弹出轻量 Toast 提示；
  * 点击分享：调起 Android 原生分享面板（系统 Intent）。
* **TTS 语音朗读**：
  * 原文与译文区域各提供独立的朗读按钮；
  * 朗读过程中按钮状态切换为“停止”，点击可随时打断播放；
  * 若系统未安装对应语言的 TTS 引擎数据，友好提示“当前设备暂不支持该语言朗读”，不得崩溃。

### 3.5 本地历史记录与收藏
* **自动记录**：每次成功翻译自动持久化至本地 SQLite 数据库。
* **防抖合并**：短时间内（如 30 秒内）相同原文与语种对的重复提交，更新时间戳而非堆叠多条重复记录。
* **历史浏览与管理**：
  * 支持按原文或译文关键词实时过滤搜索；
  * 支持单条记录滑动或点击删除；
  * 提供“清空历史”功能，清空前弹出二次确认对话框。
* **收藏夹**：可在历史列表或翻译首页点击星标收藏，支持在收藏独立标签页查看。
* **历史深链恢复**：从历史或收藏点击某条记录，直接回填至翻译主页并恢复上下文。

### 3.6 设置与通用能力
* **主题外观**：支持跟随系统、浅色模式（Light）、深色模式（Dark），切换实时生效并持久化。
* **默认目标语言**：允许用户在设置中自定义每次打开应用时的初始目标语言。
* **关于与合规**：
  * 动态读取真实版本号（Version Name）与构建号（Build Number）；
  * 展示应用离线与隐私声明；
  * 提供跳转至公网隐私政策的入口链接。

## 4. 明确排除的范围 (Out of Scope for v1.0)

为了确保 100% 聚焦首发 Google Play 稳定性与合规性，以下功能严格排除在 v1.0 之外：
1. ❌ 用户注册、登录与云端数据同步；
2. ❌ 自建云端翻译 API 或商业付费翻译接口；
3. ❌ 广告 SDK（AdMob 等）与商业化组件；
4. ❌ 应用内购买（IAP）与支付系统；
5. ❌ 相机权限与 OCR 图片翻译；
6. ❌ 麦克风权限与实时语音识别输入（STT）；
7. ❌ 社交分享打卡、生词本背单词或学习社区功能。

## 5. 非功能性需求与质量门禁

| 维度 | 指标与要求 | 验收方式 |
|---|---|---|

| **真机稳定性** | 无 Crash、无 ANR，断网重启后仍可正常进行离线翻译 | Android 实体设备覆盖验证 |
